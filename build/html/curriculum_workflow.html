Update the atlas

Sync after changes appear in the official UVic calendar.

  1. Sync and rebuild

    Refresh the approved calendar data and regenerate the atlas.

    python scripts/update_program_guide.py

  2. Check the build

    python -m unittest discover -s tests -v
python scripts/verify_static_site.py

    For template-only changes, rebuild with python scripts/build_static_site.py.

  3. Publish

    Commit the updated sources and generated site, then push. GitHub Actions validates, rebuilds and deploys GitHub Pages.

    git push
Data scope

Includes all EOS courses, programs naming the School of Earth and Ocean Sciences, and referenced supporting courses. The computing map has a separate course selection and prerequisite snapshot.

Draft proposals are tracked on the curriculum site.
